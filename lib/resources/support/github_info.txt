# WiFi Cracker 开源项目

## 项目概述

WiFi Cracker 是一个开源的网络安全工具，旨在帮助网络管理员和安全研究人员测试 WiFi 网络的安全性。本项目严格用于教育目的和合法的网络安全测试。

## 项目地址

- **GitHub 仓库**: [https://github.com/mijaclan/WiFiCracker](https://github.com/mijaclan/WiFiCracker)
- **问题追踪**: [https://github.com/mijaclan/WiFiCracker/issues](https://github.com/mijaclan/WiFiCracker/issues)

## 技术栈

- **前端框架**: Flutter
- **编程语言**: Dart
- **CI/CD**: GitHub Actions

## 主要功能

- WiFi 网络扫描与分析
- 各种加密类型的破解支持
- 字典管理与优化
- 破解历史记录与统计
- 自定义破解参数调整
